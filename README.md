# Hull Breach

*Work in progress — Boot.dev capstone project.*

A 2D platformer where you play an astronaut escaping a failing space station before your oxygen runs out, including sections where gravity itself flips on you.

## Status

Early scaffolding stage. Full purpose/setup/controls documentation will be filled in as the game is built (see the project plan for the milestone roadmap).

## Setup (so far)

```
uv sync
uv run main.py
```

Requires Python 3.13 and [uv](https://docs.astral.sh/uv/).
